## Description
This project focuses on churn prediction. It aims to provide a robust, efficient, and scalable solution using modern technologies and best practices in the field.

## Key Features
- High performance architecture
- Extensible and modular design
- Comprehensive data processing capabilities
- Easy-to-use interface and quick setup

## Tech Stack
- XGBoost\n- LightGBM\n- SHAP\n- Streamlit

## Quick Start
```bash
git clone https://github.com/iMuneebK/6G-TelecomChurn-Analytics.git
cd 6G-TelecomChurn-Analytics
pip install -r requirements.txt
python main.py
```
