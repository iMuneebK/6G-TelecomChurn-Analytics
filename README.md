A machine learning pipeline designed to predict customer churn in the context of emerging 6G network capabilities.

## 🌟 Overview
As telecom evolves from 4G to 5G and towards 6G, network metrics change. This project integrates futuristic 6G metrics such as:
- Terahertz band signal quality
- Holographic communication usage
- AI-native network reliability scores

## ✨ Features
- **Advanced ML Pipeline**: Utilizes XGBoost and LightGBM for robust classification.
- **Explainable AI (XAI)**: SHAP value integration to identify key drivers of churn.
- **Interactive Dashboard**: Streamlit app for real-time risk scoring and customer segmentation.
- **Synthetic Data Generation**: Custom script to simulate futuristic telecom usage behaviors.

## 🚀 Installation & Usage
